# Upstream source

The four skill directories in this folder are unmodified copies of
[deepmodeling/deepmd-kit/skills](https://github.com/deepmodeling/deepmd-kit/tree/59022636a82dc818a120e8c8ad0e479b136809c3/skills)
at commit `59022636a82dc818a120e8c8ad0e479b136809c3`, downloaded on 2026-08-03.

Author credits and `LGPL-3.0-or-later` declarations are retained in each upstream
`SKILL.md`. The accompanying upstream license is stored as
[LICENSE](LICENSES/LICENSE).

`dpa4/` and `deepmd-finetune-dpa4/` are original MatFlowKit project skills and are not
part of this upstream mirror. The DPA4 fine-tuning skill follows the upstream skill layout,
but its workflow and runtime safeguards were derived from MatFlowKit project validation.
